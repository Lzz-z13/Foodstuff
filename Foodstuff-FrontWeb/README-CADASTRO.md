# Cadastro de funcionário — Foodstuff

Tela disponível em `/cadastro-funcionario`, mantendo as demais telas do projeto.

### Funcionalidades
- Nome, e-mail, telefone e senha temporária.
- Máscara de telefone.
- Seleção de cargo.
- Mostrar/ocultar senha.
- Validação nativa do formulário e senha mínima de 8 caracteres.
- Cadastro salvo em `localStorage` para funcionar sem backend.
- Mensagem de sucesso após o cadastro.

### Executar
```bash
npm install
npm run dev
```
